# Bobba Hotel

A Habbo-style hotel as a Garry's Mod gamemode: play in singleplayer, with friends, or on a dedicated
server, and extend everything (furni, clothes, windows, rooms, wired) with Workshop addons.

**Website and docs: [playbobba.com](https://playbobba.com)** - what it does, how to set it up, how to make
addons, the [changelog](CHANGELOG.md) and the [roadmap](ROADMAP.md).

Work in progress - not on the Workshop yet.

The website is built from `docs/`, `website-src/`, `CHANGELOG.md` and `ROADMAP.md` with
`python3 tools/build_site.py` (needs `pip install markdown pygments`); commit `website/` with them.
