For retro owners

Why run Bobba Hotel instead of a retro stack?

Today's Habbo retros run an emulator (Arcturus, in Java), a MySQL database, a web client (Nitro) with converted assets, a CMS and a web server, each set up and kept running on its own. Bobba Hotel is one thing.

Where retros are still ahead

  • The browser. Retro players need nothing but a web page; Bobba Hotel needs Garry's Mod or the desktop app. A web client is on the roadmap.
  • Size. A retro emulator holds thousands of players at once; a Garry's Mod server holds up to 128. The custom server on the roadmap is for big hotels.
  • Years of use. The retro stack has been run and fixed by many hotels for years. Bobba Hotel is still in development.
  • Moving over. There's no importer for an existing Arcturus database yet. It's planned.
Two looks, one hotel

Every feature works in both. The hotel picks the look it starts in, and players can switch whenever they like.

Wired, and then some

Make rooms do anything

Stack Habbo's wired boxes to build games and machines. When the boxes aren't enough, drop in a script box and write a few lines of Lua.

  • Triggers, conditions, effects and add-ons, run the way Habbo's server runs them.
  • Scripts move and switch furni, whisper, teleport, count and remember.
  • Sandboxed and limited: no money, no files - and an endless loop stops the script, not the hotel.

Read about wired and scripts →

-- a script box: count visitors on a plate
memory.count = (memory.count or 0) + 1
say("You're visitor number " .. memory.count)

if memory.count % 10 == 0 then
	local lamp = room.furni("lamp_basic")[1]
	if lamp then lamp:toggle() end
end
Made to be modded

Everything is an addon

Bobba Hotel's own content is just the first addon. Yours can add furni, clothes, room layouts, starter rooms, phone apps, the hotel's page, wired boxes, settings and languages - from the Steam Workshop.

  • Settings described in your addon.lua appear in the hotel's Manage screen.
  • Events for everything that happens: rooms, chat, furni, trades, money.
  • The same code runs in Garry's Mod and in the desktop app.

Make your first addon →

-- lua/bobbahotel/addons/mypack/shared.lua
BOBBA.registry.register("starter_room", "mypack_beach", {
	name = "Beach hut", layout = "model_a",
	furni = { { kind = "mypack_parasol", x = 6, y = 4 } },
	gift = { kind = "mypack_lamp", box = "present_gen1" },
})

BOBBA.events.on("roomEntered", "mypack", function(room, unit)
	BOBBA.wired.whisper(unit, "Welcome to " .. room.info.name)
end)
